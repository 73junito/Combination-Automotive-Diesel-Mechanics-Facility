# Drawings Overview

This folder contains CAD sources, exports, templates and archive policies.

Quick references:
- Templates: `Drawings/Templates/`
- CAD sources: `Drawings/CAD/`
- Exports: `Drawings/DXF/` (generated)
- Archive: `Drawings/Archive/`

Recommended viewers/editors:
- Autodesk DWG TrueView (Windows) for DWG/DXF viewing
- FreeCAD/LibreCAD for basic editing and DXF export

Vendor-neutral exchange format: prefer DXF + PDF for sharing with stakeholders.
