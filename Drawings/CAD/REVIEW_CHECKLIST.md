# Drawing Review Checklist

Use this checklist during peer review before marking a drawing as released.

- [ ] Correct project name and sheet title in title block
- [ ] Sheet number and revision present and correct
- [ ] Units set correctly (metric/imperial) and documented in `project-metadata.json`
- [ ] All dimensions present and readable at reference scale
- [ ] No overlapping or duplicate geometry
- [ ] Layers used correctly (see `layer-styles.txt` or project standard)
- [ ] Fonts and lineweights standardized
- [ ] Annotations placed in paper space (or equivalent) when required
- [ ] Bill of Materials (if applicable) attached or exported as `BOM.csv`
- [ ] Exported PDF proof generated and visually checked
- [ ] Reviewer name and date added to `changelog.txt` or commit message

Notes:
- Minor fixes may be handled in draft branch; major revisions require new revision number.
